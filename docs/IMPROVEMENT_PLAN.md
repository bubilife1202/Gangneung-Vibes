# 📋 강릉 Vibes 2.0 - 재방문율 극대화 기획안

## 🎯 현황 분석 및 문제점

### 현재 서비스의 한계
1. **단순 정보 나열**: 네이버/카카오맵으로 검색하는 것과 차별점 부족
2. **정적인 콘텐츠**: 한 번 보면 다시 올 이유가 없음
3. **참여 요소 부재**: 사용자가 소비만 하고 기여할 수 없음
4. **개인화 부재**: 모든 사람에게 똑같은 화면
5. **재미 요소 부족**: 실용성만 있고 엔터테인먼트 가치 낮음

### 목표 재정의
- **방문 동기**: 정보 검색 → **발견의 즐거움**
- **사용 패턴**: 일회성 → **습관적 재방문**
- **사용자 역할**: 소비자 → **기여자 & 큐레이터**

## 🚀 Phase 2: 즉시 적용 가능한 개선안

### 1. 🎲 "오늘의 강릉" - 매일 바뀌는 추천 시스템

**핵심 아이디어**: 매일 접속할 때마다 다른 장소를 추천
- 오늘의 맛집 (1개)
- 오늘의 카페 (1개)
- 오늘의 숨은 보석 (랜덤 1개)
- 요일별 테마 (월: 혼밥맛집, 화: 데이트카페, 수: 현지인 추천 등)

**구현 방법**:
```javascript
// 날짜 기반 시드로 매일 다른 추천
const today = new Date().toDateString();
const seed = hashCode(today); // 날짜를 숫자로 변환
const dailyPick = spots[seed % spots.length];
```

**효과**:
- "오늘은 뭐가 나올까?" 궁금증 유발
- SNS 공유 유도: "오늘의 강릉은 동화가든!"

---

### 2. 🏆 "강릉 챌린지" - 게이미피케이션

**핵심 아이디어**: 방문 도장깨기 시스템

**챌린지 예시**:
- 🌊 **오션뷰 마스터**: 오션뷰 카페 5곳 방문
- 🍜 **순두부 정복자**: 초당 순두부집 3곳 방문
- ☕ **커피 헌터**: 강릉 로스터리 카페 7곳 방문
- 🎖️ **강릉 로컬**: 현지인 맛집 태그 10곳 방문

**구현**:
- 각 카드에 "방문 인증" 버튼 추가
- 로컬 스토리지에 방문 기록 저장
- 진행률 바 표시 (5/10 달성)
- 완료 시 뱃지 수여 + 공유 이미지 생성

**심리적 효과**:
- 수집 욕구 자극
- 완성도에 대한 집착 (8/10이면 나머지 2개 꼭 가고 싶어짐)

---

### 3. 🔥 실시간 "지금 핫한 곳" - 라이브 피드

**문제점**: "핫한 곳"이 고정되어 있어 신뢰도 낮음

**개선안**:
- **최근 클릭 수 집계**: 지난 24시간 동안 가장 많이 클릭된 장소
- **급상승 장소**: 전날 대비 클릭 증가율 높은 곳
- **시간대별 추천**:
  - 오전 9-11시: 브런치 카페
  - 오후 2-5시: 디저트 카페
  - 저녁 6-9시: 맛집/주점

**구현**:
- Google Analytics 또는 간단한 카운터 API
- 1시간마다 데이터 갱신

---

### 4. 💬 "한 줄 꿀팁" - 유저 참여 콘텐츠

**핵심**: 리뷰는 귀찮지만 한 줄 팁은 쉽다

**예시**:
```
[동화가든]
💡 "주차장 없어요, 근처 공영주차장 이용" - 익명
💡 "11시 오픈인데 11시 30분에 가면 이미 웨이팅" - 강릉러버
💡 "짬뽕순두부 + 공기밥 조합이 진리" - 맛집헌터
```

**구현**:
- 각 카드 하단에 "꿀팁 남기기" 버튼
- 모달 팝업으로 텍스트 입력 (20자 제한)
- Supabase 또는 Google Forms → Sheets 연동
- 관리자 승인 후 노출 (스팸 방지)

**효과**:
- UGC(User Generated Content)로 신뢰도 향상
- 재방문 동기: "내가 쓴 팁이 올라갔나?"

---

### 5. 🗺️ "강릉 루트 추천" - 동선 큐레이션

**문제점**: 개별 장소만 보여주고 조합은 사용자 몫

**개선안**: 테마별 코스 제공
- 🌅 **아침 커피 투어**: 안목해변 → 테라로사 → 커피커퍼 (차로 20분)
- 🍜 **순두부 & 바다 코스**: 초당순두부 → 경포대 산책 (도보 15분)
- 📸 **인스타 감성 루트**: 툇마루 → 카페델문도 → 썬크루즈 (차로 30분)

**UI**:
- 메인 페이지에 "추천 루트" 탭 추가
- 카드 3-4개를 화살표로 연결
- "전체 루트 네이버 지도로 보기" 버튼 (경유지 포함된 URL)

---

### 6. 🎁 "히든 젬 발굴" - 숨겨진 보상

**핵심**: 모든 장소를 동일하게 노출하지 않음

**아이디어**:
- 일부 장소를 "🔒 잠김" 상태로 표시
- 해금 조건:
  - "3곳 이상 방문 시 해금" (게이미피케이션 연계)
  - "친구에게 공유하면 해금" (바이럴 유도)
  - "퀴즈 맞추면 해금" (예: "강릉 3대 순두부는?")

**심리 효과**:
- 호기심 자극
- FOMO (Fear Of Missing Out)

## 🎨 Phase 3: UX/UI 개선안

### 7. 감정 기반 필터링

**기존**: 카테고리 필터 (맛집/카페)
**개선**: 상황/감정 필터 추가

```
😊 혼자 조용히
💑 데이트하기 좋은
👨‍👩‍👧‍👦 가족 외식
☔ 비 오는 날
🌅 일출/일몰 명소
```

---

### 8. "비교하기" 기능

**시나리오**: "안목 vs 경포, 커피 거리 어디가 더 나아?"

**기능**:
- 2개 장소 선택 → 나란히 비교
- 거리, 분위기, 가격대, 주차 등 비교표
- "어디 갈까 투표" (사용자 참여)

---

### 9. 지역 주민 vs 관광객 모드

**관광객 모드** (기본):
- 유명 관광지 중심
- 사진 찍기 좋은 곳 강조

**로컬 모드**:
- "#현지인맛집" 태그 필터링
- 체인점 제외
- 주차/가성비 정보 강조

## 💬 결론: 차별화 포인트

현재 강릉 관련 서비스들:
- **네이버 지도**: 정보는 많지만 큐레이션 부족, 차갑고 기계적
- **인스타그램**: 감성은 있지만 정보 파편화
- **블로그**: 정보는 자세하지만 최신성 부족, 광고 의심

**강릉 Vibes 2.0의 포지셔닝**:
> "강릉을 가장 재미있게 탐험하는 방법"
> - 정보 제공 < **발견의 즐거움**
> - 단순 검색 < **매일 새로운 추천**
> - 수동 소비 < **능동적 참여**

**핵심 가치**:
1. 🎲 **세렌디피티** (우연한 발견)
2. 🏆 **성취감** (챌린지 완료)
3. 🤝 **커뮤니티** (로컬 & 여행객 연결)
